## The problem

Every robot project tends to reinvent its own bespoke stack for simulation, control, and hardware I/O. That's slow to set up and makes it harder for AI-driven (vision-language-action) control approaches to plug into arbitrary hardware without custom glue code per robot.

## The build

URS is a Dockerized, full-stack application that brings robot simulation and control into one place: load a URDF, simulate it, and drive real hardware over CAN or UART through the same interface — a consistent hardware layer that AI/VLA control systems can target without robot-specific wiring.
