## The problem

PID control is usually taught as an abstract block diagram — three Greek-letter terms and a transfer function — before students ever see what a bad P, I, or D gain actually does to a real system. That gap between the math and the intuition is where most people lose control theory.

## The build

WebPID is a single-file, zero-dependency HTML simulator: a car drives down a road and a live PID controller steers it to stay centered. Sliders for `Kp`, `Ki`, and `Kd` update the simulation in real time, so overshoot, oscillation, and steady-state error are things you watch happen rather than terms you memorize.

## The approach

The whole simulator is one HTML file with an inline `<canvas>` render loop and no build step or dependencies — deliberately, so it can be dropped into a classroom Chromebook or a lesson page with zero setup. The physics model is a simplified bicycle-style lateral error simulation: the controller reads the car's lateral offset from the road's centerline as its error signal and outputs a steering correction each frame.

## The result

WebPID is the simulator used in the [PID Lesson Plan](/projects/pid-lesson-plan/) curriculum, pairing the visual, tunable simulation with hands-on ESP32 robot cars.
