## The problem

TSA Robotics scores on precision and repeatability as much as raw capability — a claw that can grab things isn't enough if it can't return to the same position reliably, run after run, under competition pressure.

## The build

Brutus is a VEX robot fully designed in Onshape, running custom C++. Its signature feature is a surgery-inspired precision arm paired with a versatile motorized claw, controlled through inverse-kinematics macros that let a single high-level command drive the arm to a repeatable position rather than tuning each joint by hand every run.

<Image src={systemsBoard} alt="Systems board detailing Brutus's arm, claw, and control architecture" />

## The approach

The inverse-kinematics macros were the core engineering bet: rather than programming discrete joint positions for every task, Brutus's control system solves for the arm's joint angles given a target end-effector position, the same approach used in "real" robotic arms, scaled down to VEX hardware and C++. That's what made the arm's surgery-inspired precision motion actually repeatable under competition conditions instead of drifting run to run.
